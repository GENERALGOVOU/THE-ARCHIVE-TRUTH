# THE-ARCHIVE-TRUTH

THIS ARCHIVE IS THE TRUTH!

Minimal searchable static archive of 50 documented Western covert operations, human experiments, and surveillance programs.

## Site
Open `index.html` or enable GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Files:
- `index.html` — UI
- `styles.css` — minimal styling
- `app.js` — search / filter / modal
- `data.js` — 50 entries (edit to add up to 100)

## Standards
- Only operations with declassified files, court rulings, official admissions, or authenticated leaks.
- Disputed / proposed items are labeled as such (e.g. Northwoods, Strategy of Tension).
- Each entry has a “Start here” pointer (Church Committee, NARA, etc.) — add direct archive links via PR.

## Contribute
Add entries to `data.js` following the existing schema. Max 100 per site scope.
